# Evidence and release provenance

## What the release establishes

This repository is a maintained PyTorch reference implementation of HDRNet.
The paper result tables describe the authors' manuscript experiments. They are
not generated during installation, CI, or synthetic smoke tests. Full benchmark
training, original checkpoint conversion and matching the manuscript's reported
parameter/FLOP counts remain separate validations.

The v0.2 FloodNet graph was measured at **30,870,552 parameters** on Python 3.12
and PyTorch 2.14.1 CPU. This is a confirmed capacity difference from the
manuscript's 25.83M model. The original training graph/weights are required to
resolve it; synthetic tests do not establish equivalence to that archived model.

The source includes three tested mechanisms: training-only category-prior
attention, selected-class directional boundary refinement, and independent
object-conditioned categorical/ordinal state heads. Engineering tests establish
their tensor behavior, gradients and operational contracts, not final accuracy.

## Release checklist for an exact experimental archive

An exact experiment release additionally needs original executable configurations,
dataset split manifests, pretrained initialization hashes, final checkpoint hashes,
seed-level evaluations, hardware/software versions and the original measurement
scripts. These files should be authored from experiment records. A newly improved
reference implementation cannot establish the provenance of old experiments.

`docs/baselines.md` retains the previous release's configuration notes, including
the reported stride and optimizer-group differences. Resolve those notes against
the archived runs before calling this tree an exact reproduction package.

## v0.2 compatibility

- State heads now belong to individual object categories. RescueNet building
  damage uses monotone cumulative thresholds; clear/blocked roads use a separate
  categorical head. FWISD's floodwater/natural-water factor shares the water
  object category.
- State probabilities depend on the image features. The previous shared-score
  class softmax cancelled its common score.
- Boundary supervision consumes raw logits, and ignored pixels do not contribute
  to BCE/Dice. Coarse composition uses soft-label cross-entropy.
- Hierarchical consistency includes object and state factors, with valid-pixel
  normalization. Empty state regions contribute finite zero losses.
- The prior is estimated from training masks, installed before training and saved
  in model checkpoints.
- Metrics retain the original confusion matrix and reject invalid labels. A
  per-class F1 must agree with `200 * IoU / (100 + IoU)` when IoU is in percent;
  the arithmetic mean of F1 is not derived from mean IoU.

These corrections change the old public model graph and loss. Old checkpoints
must not be relabeled as v0.2. The loader uses strict key checks and rejects
incompatible head weights. Use the Git history to recover the earlier implementation.

## Contributing evidence

Attach evaluation JSON and the corresponding `run.json` when reporting results.
Distinguish paper-reported measurements from measurements generated by this
release. Never insert manuscript scores into an executable metrics output.
